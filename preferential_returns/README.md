# Preferential returns
**An old project**
This is an implementation of the Explorer and Preferential Returns model, I was originally going to use this to simulate
asymptotic visitation frequencies on a lattice that can be seperated into a work/non-work visits, and then explore the
difference between just using work visitation vs other types of visists.
Aligning this to data, scaling an agent based model to a whole population and doubts about validity of using this model
for this approach meant I didn't do this, but I've kept the implementation here since it took a load of effort to
implement the probability distributions e.t.c
